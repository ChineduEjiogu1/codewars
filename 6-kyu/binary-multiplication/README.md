<h2><a href=https://www.codewars.com/kata/596a81352240711f3b00006e/train/c target="_blank">Binary multiplication.</a></h2><h3>6 kyu</h3><p>The goal of this kata is to multiply two integers using the <a href="https://en.wikipedia.org/wiki/Ancient_Egyptian_multiplication" data-turbolinks="false" target="_blank">ancient Egyptian method</a>, which only requires divisions and multiplications by two, and additions.</p><p>Your function takes two integers as input. It shall return a list of the steps in the multiplication.</p><p>Let <code>m</code> be the largest and <code>n</code> the smallest. While <code>m</code> is superior to <code>0</code>, at each step:</p><ul><li>if <code>m</code> is not divisible by <code>2</code>, add <code>n</code> to the list</li><li>divide <code>m</code> by <code>2</code> (integer division)</li><li>multiply <code>n</code> by <code>2</code></li></ul><p>At the end, return the list in descending order.The result of the multiplication is the sum of the list elements, but you have to return only the list.</p><h2 id="input">Input</h2><p><code>n</code> and <code>m</code> integers, from <code>0</code> to <code>10,000</code>.
